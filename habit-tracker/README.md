# Habit Tracker

Веб-приложение для формирования и отслеживания привычек.

## Используемые технологии

- React (Create React App)
- Node.js
- Express.js
- PostgreSQL
- JWT
- REST API
- Docker
- PWA

## Основной функционал

- регистрация и авторизация;
- создание привычек;
- редактирование привычек;
- удаление привычек;
- архивирование привычек;
- календарь выполнений;
- статистика;
- браузерные уведомления;
- оффлайн-режим.

## Запуск проекта

```bash
docker compose up --build
```

После запуска:

Frontend:

```
http://localhost:3000
```

Backend:

```
http://localhost:5000
```

PostgreSQL:

```
localhost:5432
```

## Структура проекта

- frontend/ - клиентская часть
- backend/ - серверная часть
- database/ - SQL-структура базы данных
